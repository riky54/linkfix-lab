# LinkFix Lab

Demo portofolio *front-end troubleshooting* untuk pekerjaan **“Perbaiki Link Website Macet”**. Ini adalah simulasi mandiri, bukan hasil pekerjaan di situs klien.

## Yang diperlihatkan

- Tiga penyebab link/tombol tidak merespons: overlay dengan `z-index`, `pointer-events: none`, dan `preventDefault()` yang tidak tepat.
- Perbandingan kondisi sebelum dan sesudah perbaikan yang bisa dicoba langsung.
- Alur kerja: reproduksi masalah, diagnosis, perbaikan, pengujian desktop/ponsel, dan catatan perubahan.
- Tata letak responsif, navigasi keyboard, serta pesan hasil yang diumumkan melalui `aria-live`.

## Jalankan

Buka `index.html` di browser. Tidak ada proses build atau dependensi JavaScript.

## Catatan teknis

Demo menggunakan HTML, CSS, dan JavaScript. Kasus sebelum perbaikan sengaja dibuat gagal. Mode sesudah perbaikan menunjukkan interaksi yang berhasil. Tidak ada koneksi ke website klien atau klaim bahwa proyek klien telah diselesaikan.

## Pengujian singkat

1. Pilih setiap kasus dan coba tombol **Lihat detail** pada dua kondisi.
2. Pastikan mode **Sebelum diperbaiki** menampilkan gejala dan mode **Sesudah diperbaiki** menampilkan pesan berhasil.
3. Uji tab kasus dengan tombol panah, lalu tombol demo dengan Enter.
4. Uji lebar desktop dan ponsel.
